# Ocean V4 Crest Foam — Phase 1

Phase 1 is an ephemeral material response, not a foam simulation. It combines
positive displaced height with the already reconstructed LONG+MID slope; MID
only fragments the result and SHORT never triggers coverage. A world-space
distance fade limits foam to the useful near and middle field.

The implementation has no history, topology texture, compute dispatch, extra
sampler, readback, Surface Foam, breakers or boat/wake contribution. When the
crest signal disappears, so does the foam. Those omitted systems remain future
decisions rather than hidden dependencies.
